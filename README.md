# Astro + GenCSS Starter

A minimalist, high-performance Astro starter template powered by **GenCSS / FEWD** design tokens, strict **BEM** CSS architecture, and **CSS logical properties**—with zero runtime overhead.

---

## Highlights

- **Fluid Mathematical Scalability**: Fully fluid typography (`--text-xxs` through `--text-xxxl`) and spacing curves (`--space-xs` through `--space-3xl`) calibrated with mathematical ratios and fluid `clamp()` formulas, plus container-query scaling helpers (`.cq-fluid`, `.cq-spacing`).
- **Modern Minimalist Dark Theme & OKLCH Engine**: Sleek obsidian and carbon surfaces, high-contrast accents, and built-in transparency scales (10% to 90%) engineered with perceptually uniform `oklch` color primitives.
- **Two-Layer Token Architecture**: Clear separation between Layer 1 design primitives (raw scales for color, type, space, radius, shadow) and Layer 2 semantic design tokens (contextual gaps, semantic theme roles, and component presets).
- **Strict BEM Methodology**: Scoped, maintainable component classes (`.c-block__element--modifier`) and layout wrappers (`.l-container`, `.l-section`). Zero utility frameworks, zero class soup.
- **100% CSS Logical Properties**: Flow-relative properties (`padding-block`, `margin-inline`, `inline-size`, `max-inline-size`, `inset-block-start`) authored across all styles for resilient internationalization and modern layout structure.
- **Zero Runtime CSS Overhead**: Plain, standards-compliant CSS bundled at build time with Astro, requiring zero JavaScript runtime or runtime CSS-in-JS dependencies.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.17.1 or higher)
- [npm](https://www.npmjs.com/) (or pnpm / yarn)

### Using as a Template

This repository is configured as a GitHub **Template Repository**, allowing you to spin up a new project with a clean git history.

#### Option A: Via GitHub Web Interface
1. Visit the [`gdcrosbie/astro-gencss-starter`](https://github.com/gdcrosbie/astro-gencss-starter) repository.
2. Click the green **"Use this template"** button and select **"Create a new repository"**.
3. Set your repository name, choose visibility, and click **"Create repository"**.
4. Clone your new project and install dependencies:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   npm install
   ```

#### Option B: Via GitHub CLI (`gh`)
Create, configure visibility, and clone your new project in a single command. Replace `my-project` with your desired repository name, and swap `--public` for `--private` as needed:

```bash
# Public repository:
gh repo create my-project --template gdcrosbie/astro-gencss-starter --public --clone

# Private repository:
gh repo create my-project --template gdcrosbie/astro-gencss-starter --private --clone

cd my-project
npm install
```

#### Option C: Standard Clone
Alternatively, clone directly and specify your own project directory name instead of `my-project`:

```bash
git clone https://github.com/gdcrosbie/astro-gencss-starter.git my-project
cd my-project
npm install
```

### Development Server

Start the local development server:

```bash
npm run dev
```

To run the dev server in the background:

```bash
npx astro dev --background
```

Manage background sessions with:
- `npx astro dev status`
- `npx astro dev logs`
- `npx astro dev stop`

### Building for Production

Compile static assets to the `dist/` directory:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Design System & Styling Conventions

### 1. Token Source (`src/styles/tokens.css`)

All styling is driven by native CSS custom properties generated by GenCSS / FEWD, structured into two core layers:

- **Spacing Scale**:
  - Fluid spacing steps: `--space-xxs`, `--space-xs`, `--space-s`, `--space-m`, `--space-l`, `--space-xl`, `--space-2xl`, `--space-3xl`.
  - Negative spacing helpers: `--space-neg-xs`, `--space-neg-s`, `--space-neg-m`.
  - Gaps: `--gap-xs`, `--gap-s`, `--gap-m`, `--gap-l`.
  - Contextual spacing: `--gap-content` (default `--space-l`), `--gap-grid` (default `--space-xl`), `--gap-container` (default `--space-2xl`).
  - Shorthand aliases: `--padding-xs` through `--padding-2xl`, `--margin-xs` through `--margin-2xl`.

- **Colors & Transparency (OKLCH)**:
  - Palette families: `--primary`, `--secondary`, `--tertiary`, `--accent`, `--base`, `--neutral`.
  - Step shades: `-light-2`, `-light-1`, `[base]`, `-dark-1`, `-dark-2`.
  - Built-in transparency steps: `--primary-trans10` through `--primary-trans90`, `--accent-trans10` through `--accent-trans90`, `--white-10` through `--white-90`, `--black-10` through `--black-90`.
  - Theme semantic roles:
    - `--background`: Maps to `--base-dark` / `--bg-dark`
    - `--surface`: Maps to `--base` / `--bg-light`
    - `--surface-raised`: Maps to `--base-light-1` / `--bg-darker`
    - `--color`: Main text color (`--white` / `--text-on-dark`)
    - `--color-muted`: Secondary text color (`--neutral` / `--text-light`)
    - `--border-color`: Hairline divider color (`--white-10` / `--border`)

- **Borders, Radius & Shadows**:
  - Semantic radius: `--radius-s`, `--radius-m`, `--radius-l`, `--radius-full` (pill), `--radius-card`, `--radius` (default `--radius-m`).
  - Numeric radius primitives: `--radius-1` (2px) through `--radius-5` (16px), `--radius-pill` (9999px).
  - Shadows: `--shadow-s`, `--shadow-m`, `--shadow-l`, `--shadow-card`, and primitives `--shadow-1` through `--shadow-4`.
  - Transitions: `--transition-fast`, `--transition-base`, `--transition-slow`, `--transition`.

- **Container-Relative Queries**:
  - Apply `.cq-fluid` to scale `--text-*` based on container inline size (`cqi`).
  - Apply `.cq-spacing` to scale `--space-*` based on container inline size (`cqi`).

### 2. Typography Rules

- **Type Scale**: `--text-xxs`, `--text-xs`, `--text-s`, `--text-m`, `--text-l`, `--text-xl`, `--text-xxl`, `--text-xxxl`.
- **Display & Feature Roles**: `--text-display` (`--text-xxxl`), `--text-feature` (`--text-xxl`).
- **Heading Sizes**: `--h1` (`--text-xl`), `--h2` (`--text-l`), `--h3` (`--text-m`), `--h4` (`--text-s`), `--h5` (`--text-s`), `--h6` (`--text-xs`).
- **Heading Properties**: `--font-heading`, `--weight-heading`, `--leading-heading`, `--tracking-heading`, `--style-heading`.
- **Body Properties**: `--font-body`, `--weight-body`, `--leading-body`, `--tracking-tight`, `--tracking-wide`, `--tracking-wider`.
- **Monospace Elements**: `--font-mono` for code snippets, badges, and technical tags.

### 3. Layout Primitives

Author consistent layouts using the container and section abstractions:

- **Container (`.l-container`)**:
  ```css
  inline-size: 100%;
  max-inline-size: var(--container-width, 1200px);
  margin-inline: auto;
  padding-inline: clamp(1rem, 4vw, var(--space-m));
  ```

- **Section Spacing (`.l-section`)**:
  ```css
  padding-block: var(--section-block, var(--space-xl));
  ```

### 4. CSS Logical Properties

Always author flow-relative logical properties instead of physical dimensions:
- **Padding**: `padding-block`, `padding-inline` (never `padding-top/bottom/left/right`)
- **Margins**: `margin-block`, `margin-inline` (never `margin-top/bottom/left/right`)
- **Dimensions**: `inline-size`, `max-inline-size`, `block-size`, `min-block-size`
- **Borders**: `border-block-start`, `border-block-end`, `border-inline-start`, `border-inline-end`
- **Positioning**: `inset-block-start`, `inset-inline-start`, `inset`
